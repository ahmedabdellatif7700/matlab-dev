# Staged 60 GHz equalizer design

`main.m` is the full experiment entry point. It explicitly configures the physical link, creates independent discovery waveforms, invokes Python model search, locks conditions/architectures, generates fresh confirmation data, retrains without test selection, generates tables/figures. Existing five-scenario sweeps remain available through `run_all_scenarios.m`; `legacy_main.m` retains the hardware workflow.

The four candidate families isolate MZM distortion with 16-QAM, MZM plus an RF echo with 64-QAM, RF PA amplitude/phase distortion plus an echo with 16-QAM, and RF PA plus small-signal optical DSB fading with 64-QAM. All use a 60 GHz envelope carrier, 1 Gbaud, RRC rolloff 0.25 and eight waveform samples/symbol. See `+mmw/design_candidates.m` for the declared discovery grid. These are hypotheses to test, not four assumed successes.

Python `equalizer.py` uses the shared `RealEqualizer` and `activations/` registry to search bitwise neural classifiers with variable hidden sizes, tanh, SiLU, softsign, fixed multilevel and learned multilevel activations. The learned activation is an experimental ablation; improvement and novelty must not be assumed. Outputs are Gray-bit logits, so the topology is not limited to 4–12–2. Standardization is fitted on training data. AdamW and an LBFGS polishing stage retain the lowest validation BCE checkpoint.

The controls include complex FFE, full real Volterra regression up to order 7, Volterra bit classifiers up to order 5 and RBF kernel bit classifiers up to 256 centers. Bit classifiers control for the benefit of the bitwise objective. Ridge and bandwidth choices use validation data. Each receiver uses the same current and previous complex samples; conclusions are restricted to this observation window and tested receiver catalog, not all possible conventional receiver designs.

Discovery MAT files contain no test arrays. `selection.json` freezes one condition and network per qualifying family. Three independent confirmation seeds use 18,000 training, 6,000 validation and 50,000 test symbols each. A successful efficiency case requires the NN to meet its locked BER target while tested receivers costing no more fail it, and the cheapest tested classical receiver meeting the target to require at least 1.5 times as many real multiplications. Unrestricted classical results remain visible. This is arithmetic efficiency, not proof of hardware power, latency or unavoidable neural processing.

Final tables distinguish hard-decision EVM from analog equalizer EVM. They include BER errors/counts, nominal binomial Wilson intervals and paired contiguous-symbol-block bootstrap differences. Temporal dependence and seed variability matter; zero observed errors do not establish zero true BER. Activation evaluations are separate from multiplications. Polynomial accounting assumes shared lower-order monomials; additions and fusible affine normalization are excluded. Classical inference currently uses float64 and NN inference float32; parameter counts are not memory-byte comparisons.

The MZM RF-fundamental approximation and optical small-signal DSB approximation are never cascaded in the MZM candidates. The PA/optical cascade is phenomenological and is not a calibrated optical hardware model. The controlled echoes are simulation stress conditions. The supplied Liu and Song papers motivate these impairment families; this experiment does not reproduce their apparatus or figures numerically.

## Configuration and MAT-file interface

Edit physical settings in `+mmw/design_config.m` and candidate conditions in `+mmw/design_candidates.m`. Edit neural widths, activations, learning rates, restart count and baseline search choices in `python/config.py` (`NETWORKS`, `EXTENDED_NETWORKS`, `RESEARCH`). MATLAB always invokes `python/equalizer.py`, using optional `--run` and `--phase` arguments for the research campaign. Calling `equalizer.py` without arguments retains the original dataset/training/ONNX/fixed-point workflow.

Research datasets retain the familiar `X`/`Y` MAT arrays; `split_counts` declares independent train/validation/(confirmation-only) test segments. Older explicitly split research datasets remain readable. Research inference writes `equalized_output.mat` with `rx_before`, `tx_reference`, `rx_equalized` and `bits_predicted`. The bit receiver's `rx_equalized` values are hard-decision constellation symbols, explicitly labeled by `output_kind`; they are not analog ONNX reconstructions. Existing ONNX/Q8.8 output files and parameter names remain compatible for the legacy workflow. Arbitrary floating-point MLPs require `EXPORT_FIXED_POINT=False` when using that workflow; the existing RTL still supports its original topology.

There are no new standalone verification scripts in this workflow. Training/validation/test separation and receiver metrics remain part of the experiment itself. Validation-selected targets may use the reference grid or the midpoint between the NN and the best classical receiver below 1.5 times its arithmetic budget; the origin is recorded. Discovery NN BER must be at most 3.8e-3. Three training restarts are selected by validation BCE on each independent confirmation seed, without test-based selection. SNR curves use frozen receivers on fresh payloads and measure generalization, not per-SNR retraining.
